The Python Software Foundation is the charitable organization behind the Python programming language.

Security notice: the emSign root CA has been removed from certifi. Upgrade certifi, pip, uv and sigstore now.   See more

We support the Python Community through...

Grants

In 2024, the PSF awarded $655,000 USD to 257 groups or individuals in 61 countries around the world.

Infrastructure

We support and maintain python.org, The Python Package Index, Python Documentation, and many other services the Python Community relies on.

PyCon US

We produce and underwrite the PyCon US Conference, the largest annual gathering for the Python community. Support from sponsors, attendees, PyLadies, and CPython enabled us to award more than $384,000 USD in travel grants to 254 attendees for PyCon US 2025.
