MCP server for AI agents: local and hosted

vims-mcp exposes your local VIMS to Claude Code, Cursor, Codex, Devin, Antigravity, Kilo, Gemini CLI, Cline, and VS Code; mcp.vims.com is the hosted endpoint for agent discovery and browser workflows.

What it does

VIMS speaks MCP in both directions. As a client, it connects external servers (GitHub, Postgres, Playwright, Blender, …) for its own agents. As a server, vims-mcp gives any MCP client live control of the local platform, and mcp.vims.com gives browser-based agents a hosted route to public VIMS services.

How it works

  1. Add vims-mcp (local) or mcp.vims.com (hosted) to your MCP client
  2. Call tools/list to see what is available
  3. Call tools under VIMS permissions and approvals

Two MCP surfaces

Use the one that matches where the work lives. Neither hands a hosted service your private keys.

◆
vims-mcpLocal stdio MCP server. Proxies approved tool calls to the VIMS daemon on your machine: agents, browser, flows, databases, knowledge, Nostr identity, settings.
◆
mcp.vims.comHosted Streamable HTTP endpoint. Public agent discovery and marketplace actions; the browser-facing foundation for authorized VIMS web-surface workflows.
◆
keys.vims.com boundaryAgents can request identity creation and management, but secret key material never leaves the user-controlled vault. Signing stays permissioned.
{
  "mcpServers": {
    "agent-vims": {
      "url": "https://mcp.vims.com",
      "transport": "streamable-http"
    }
  }
}

FAQ

How do I connect Claude Code?

Point it at the vims-mcp binary (stdio) with VIMS_URL set to your local daemon, or add https://mcp.vims.com as a remote connector.

Can a browser agent create identity keys?

It can request creation and management through the identity tools; the private key is generated in the keys.vims.com vault and signing stays user-authorized.

Does mcp.vims.com hold my keys?

No. Reads are public; writes return calldata for your own wallet or vault to sign.

How does VIMS MCP connect to the rest of VIMS?

It shares your identity from keys.vims.com and is reachable by agents through MCP and Flow, so it works alongside every other VIMS app.
